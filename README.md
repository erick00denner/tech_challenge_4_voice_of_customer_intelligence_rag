
# Voice of Customer Intelligence com RAG

Tech Challenge — Fase 4 | Pós-Tech FIAP

## Objetivo

Desenvolver uma aplicação de inteligência de voz do cliente
utilizando Retrieval-Augmented Generation (RAG) para consultar
avaliações de consumidores do dataset público Olist.

## Tecnologias previstas

- Python 3.12
- Streamlit
- LangChain
- Sentence Transformers
- ChromaDB
- LLM via API

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

Fonte:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Estado do projeto

Etapa 0 — Configuração do ambiente de desenvolvimento.

## Estrutura

- `src/`: preparação, indexação e pipeline RAG
- `data/`: datasets locais, não versionados
- `docs/`: decisões técnicas e documentação
- `tests/`: testes de recuperação e geração
- `app.py`: interface Streamlit
